# 页面分工、主题词与放词位置

步骤 1–3 用。词例是电子元器件和工业品行业的通用写法，只说明分法，不代表真实搜索量；做真实站点时以关键词研究表和结果页为准。

## 1. 页面类型分工总表

先看意图（主轴），再看属性。最后一列最要紧：每类页面都有不该去抢的词。

| 页面类型 | 承接的词（意图 · 细类） | 主要属性 | 词例 | 不要抢的词 |
|---|---|---|---|---|
| 首页 | 导航词（品牌、站名）；未带意图修饰的全站主题 | 品牌、全站主题 | `<品牌名>`、`industrial ethernet connectors` | 各品类的细分词、长尾词 |
| 总页（产品中心、方案总页、新闻中心这类总入口） | 商业 · 产品浏览，用统称 | 统称 | `magnetic components` | 具体品类词 |
| 分类页（二、三级） | 商业 · 产品浏览、找厂家、找供应渠道 | 品类 | `ethernet transformer`、`ethernet transformer manufacturers` | 带速率、系列、型号的下级词 |
| 系列页 / 选型页（四级） | 商业 · 产品浏览（带参数、系列） | 品类 + 参数 / 系列 | `cat6 inline coupler` | 上级页的品类通用词 |
| 型号页 | 商业 · 询价、样品、现货与下单；信息 · 参数资料（例外） | 型号 | `<料号> datasheet`、`<料号> pinout` | 品类词 |
| 替代对照页（或对照文章） | 商业 · 替代查询 | 竞品型号 | `<竞品料号>`、`<竞品料号> equivalent` | 自家型号词 |
| 技术文章 | 信息 · 概念、原理、选型方法、故障排查、技术对比、标准法规、行业资讯 | 品类、技术概念 | `how ethernet transformers work`、`cat5e vs cat6` | 品类商业词、型号词 |
| 应用领域 / 方案页 | 信息 · 设计应用（例外） | 应用、行业 | `poe switch reference design` | 分类页的主题词（只用同义叫法作锚文本链回） |
| 关于页 / 能力页 | 导航词；不带品类的找厂家、找供应渠道；服务词 | 公司、服务 | `engineering support` | 产品词 |
| 样品、定制、询价页 | 商业 · 样品、定制、询价 | 服务 | `<品类> samples`、`custom <品类>` | 品类主题词 |

**默认规则**：商业词进产品类页面，信息词进技术文章。两个例外：带型号的参数资料词（`<料号> datasheet`）进型号页，因为答案就在型号页上；设计应用类的信息词进应用领域页。

**层级不是关键，关键是主题由谁承接。** 一个结构上是四级的页面，如果它就是某个品类词的承接页，它就起分类页的作用。

## 2. 九个商业细类各进哪类页面

页面上「要有什么」只列出来帮助判断承接页对不对口；具体怎么写交 seo-content-writing，能不能写某个说法以口径文件为准。

| 商业细类 | 承接页 | 页面上要有 |
|---|---|---|
| 产品浏览 | 分类页、系列页 | 系列概述、选型表、各系列区别、应用、资料下载 |
| 比较挑选（比品牌、供应商、可买的产品） | 选型指南、系列页 | 选型依据、对照表、适用场景 |
| 替代查询 | 替代对照页、型号页 | 原型号与候选型号的参数对照、差异、验证方法 |
| 找厂家 | 带品类的进分类页；不带品类的进关于页 | 我们是谁、哪些自产、证书与检测报告 |
| 找供应渠道 | 同上 | 自产还是代理、怎么供货、联系方式与回复时效 |
| 询价 | 型号页、询价入口 | 询价表单、需要客户提供的信息 |
| 现货与下单 | 型号页、询价入口 | 下单方式；交期按口径文件写 |
| 样品 | 样品页 | 申请方式和流程 |
| 定制 | 定制页 | 定制范围、流程、评估时间 |

商业词页面的「答案」是产品和下一步：参数、对照、资料、入口。buy、price、supplier 这类词写成文章，会和产品页抢词，读者也找不到询价入口。

## 3. 信息词的九个细类

概念定义、原理机制、参数资料、选型方法、设计应用、故障排查、标准法规、技术对比、行业资讯。

- 默认都进技术文章，一篇主打一个细类，次要问题放进问答。
- 例外：参数资料（型号 + datasheet / pinout）进型号页；设计应用进应用领域页。
- 两三句话能答完、没有独立搜索需求，或答案离不开某个产品参数的小问题，写进那个页面的问答，不单独成篇。

## 4. 比较类的词

按比较对象分，不按有没有「vs」分：

| 比的是什么 | 意图 | 承接页 | 例 |
|---|---|---|---|
| 技术、规格、原理 | 信息 · 技术对比 | 技术文章 | `cat5e vs cat6`、`smd vs through hole transformer` |
| 品牌、供应商、可以直接买的产品，带 best、top、review | 商业 · 比较挑选 | 选型指南、系列页 | `best <品类> brands`、`top <品类> suppliers` |

注意：承接「best <品类>」这类词，不等于页面上可以写 best、leading 这类最高级。说法以口径文件为准。

## 5. 没有意图修饰的词

光秃秃的品类名、料号，词面看不出意图，要看结果页：

1. 无痕窗口搜这个词，记下前 10 名分别是什么类型的页面（分类页、零售商品页、教程、百科、原厂型号页）。
2. 前排多是哪类，就由我们同类型的页面承接。
3. 量大、但前排多是零售或教程的品类词：搜的人多半不是我们的买家（推断）。它仍可以作分类页的主题词，但给一个合格的承接页即可，不当重点，也别指望它单独带来询盘。

## 6. 主题词、同义叫法、辅助词、别人的主题词

| 角色 | 一页几个 | 放在哪 | 规则 |
|---|---|---|---|
| 主题词 | 1 个 | 标题、H1、首段、导航名、面包屑、入链锚文本 | 取量大、贴近买家的叫法 |
| 同义叫法 | 按实际 | 首段或问答里各自然提一次；应用领域页用它们写正文，作锚文本链回本页 | 核过结果页重合才并进来 |
| 辅助词 | 不设个数 | 小标题、选型维度、参数表、问答 | 同一主题、同一意图；不堆砌 |
| 别人的主题词 | — | 只作锚文本，链到它的承接页 | 本页不展开 |

依据：
- Google《搜索要素》（2025-12-10）：用用户会搜的词，放在标题、主标题、图片 alt、锚文本这些显眼位置。
- Google《搜索如何运作》：要覆盖相关内容，而不是重复同一个词。
- 必应网站管理员指南（访问 2026-10）：每个网址聚焦一个主题。

官方没有给辅助词个数，所以本方法不设个数，只看自然、有没有堆砌。

## 7. 同义词怎么判（中文同样适用）

中文的同一个产品常有好几种叫法（如「网络变压器」「网口变压器」「LAN 变压器」「网络隔离变压器」），英文也有（如 `ethernet transformer`、`lan transformer`、`ethernet magnetics`）。五步：

1. **列候选说法**。
2. **比结果页前 10 的重合**：在无痕窗口分别搜，数相同的完整网址个数；至少 3 个相同归同一组、由同一页承接（Keyword Insights 默认阈值，经验值），很少或没有就分开承接。词义相近不等于搜索引擎认为相同：例如 `rj45 connector` 前排多是网线水晶头，`rj45 jack` 多指板端母座，正式归组前必须看结果页。
3. **查量**：英文用关键词工具；中文用百度营销关键词规划师、百度指数的对比（最多 5 个词）。没有工具就写「未知」，用下拉词和结果页判断有没有人搜。
4. **加量**：真同义词在工具里分开计数，可以相加估算整个主题的需求（百度指数用「+」累加，最多 3 个）；同一个词的变体写法（单复数、空格、连字符、大小写）工具已经合并计数，不能再加。
5. **定主题词**：取量大、最贴近买家的叫法；其他叫法在首段或问答里各提一次，应用领域页用它们写正文、作锚文本链回分类页。

不要为每种叫法各建一页，也不要把几种叫法都堆进首屏主标题：
- 百度劲风算法（2020-02）打击与标题不符、内容空洞的聚合页；
- 必应官方博客（2025-12-19）：大模型会把近似重复的网址归为一组，只选一个代表页；
- 几种叫法挤进一个标题，是不自然的重复，有堆砌风险（Google 垃圾政策）。

GSC 的「查询分组」（2025-10-27 推出）把同一问题的不同写法合成一组，可以当作 Google 视角的参照。

改了主题词以后，网址不跟着改（第 3 条原则）。

## 8. 长尾词

**定义**：在核心词上加限定，定向、专一地描述某一个具体问题或某一类产品、场景的词。通常单个量小、意图明确，但量小只是倾向，不是定义，也不凭某一个月的量下结论。

**不算长尾**：同一个词的变体写法（单复数、空格、连字符）；同义叫法。它们和原词是同一个主题，按第 7 节处理。

**默认放进最相关的已有页面**：分类页、系列页、型号页或文章。拿不准就先放最接近的页面，4–8 周后看搜索控制台里这个词的展示落在哪一页、排第几，再调整。

**单独建页的四个条件**（经验做法，四条都满足才建）：
1. 结果页前排是专门讲它的页面，不是综合页（参考 Ahrefs 长尾词指南 2026-05-27 用结果页判断是否单独成页的做法）；
2. 我们有独立的东西可写：型号、参数、应用、图纸；
3. 有需求证据：搜索量、搜索控制台展示或询盘；
4. 建好以后，有页面会链到它。

判断示例（示意，不是真实数据）：

| 词 | 判断 | 处理 |
|---|---|---|
| `rj45 magjack` | 品类里的一种结构叫法，已有页能答全 | 放进所属分类页，小标题或问答里写到 |
| `waterproof rj45 connector` | 有专门产品线和内容、结果页前排是专门页、有量、有入口 | 单独建页 |
| `rj45 dust cover` / `dust cap` / `dust plug` | 同义叫法 | 并成一个主题，量最大的作主题词 |
| `industrial <品类>`（我们没有对应产品线） | 第 2 条不满足 | 先不建；对照表里写「不做」和原因 |
| `<品类> center tap`（具体技术问题） | 信息词 · 原理机制 | 写一篇技术文章，或并进已有文章 |
| `<竞品料号> equivalent`，几百个只换型号 | 批量造页 | 不做空页；有真实对照内容的才由对照页承接 |

为长尾词批量造「X for Y」「X equivalent」这类只换修饰词或型号的页面，属于 Google 垃圾政策（2026-08-28）里的滥用规模化内容。

## 9. 首页、总页、能力页

- **首页**：只写首页自己的主题：品牌加全站主题；产品线名作辅助词放在产品卡片上；各品类的长尾词交给分类页、应用页和文章，首页只放链接过去。把几十个目标词全写进首页，主题被稀释，又和自家分类页争同一个词，不自然的重复还属于关键词堆砌的风险。收录本身一般不受影响，受影响的是排名和匹配（推论）。
- **首页和分类页用同一个品类词**（首页的总括主题自然会包含它）：对照表「承接页」只填分类页，「首页用法」一列写首页怎么提到它（标题、卡片、指向分类页的链接）。是不是内耗，按 cannibalization-duplicates.md 的查法看数据，不凭页面安排下结论。
- **总页**（产品中心、方案总页、新闻中心这类总入口）：认领一个别的页面没有认领的统称；具体品类词交给分类页。有的站约定「总页只放链接、不展开品类词」「产品词只出现在器件卡片上」，这是站点约定，不是行业标准，写进站点档案再照做。
- **能力页、关于页**：认领服务词（如 `engineering support`、`design support`）和不带品类的公司词；带品类的找厂家词归分类页。

## 10. 放词位置表

这里只讲「出现在哪里」，标题、描述怎么写交 seo-tdk-page-elements。

| 页面类型 | 主题词放在 | 辅助词放在 | 链出到 | 不要做 |
|---|---|---|---|---|
| 首页 | 标题、H1、首屏一句话 | 产品线卡片名 | 各大类、品类页 | 把各品类长尾词铺进正文 |
| 分类页（二、三级） | 标题、H1、首段、导航名、面包屑、入链锚文本 | 小标题、选型维度、问答；同义叫法首段提一次 | 下级页、代表型号、集群文章 | 复述上级页的介绍 |
| 系列页 / 选型页 | 标题、H1：系列名 + 参数 | 应用场景、问答 | 型号页；链回上级 | 照搬上级页的长文 |
| 型号页 | 标题、H1：料号 + 品类 + 关键参数 | 参数表、应用说明 | 系列页、替代对照 | 用全站共用条款当正文 |
| 技术文章 | 标题、H1：信息词（问题、原理） | 小标题 | 支柱页、型号页 | 拿品类商业词当标题 |
| 应用 / 方案页 | 标题、H1：应用词 | 方案说明；产品同义叫法写正文 | 器件卡片；同义叫法作锚文本链回分类页 | 罗列产品品类词 |

- **不设密度指标**：主题词出现在这些位置即可，不为凑次数重复写。
- 「每页一个 H1」是常见的写法约定，不是搜索引擎要求：Google《SEO 新手指南》（2025-12-10）说没有理想的标题数量。
- 有的站约定「首屏主标题只放主题词、辅助词不进首屏」，这是站点约定，按站点档案执行。
- **怎么查**：看源代码，逐项对这张表，对不上的记进对照表的「下一步」。

## 11. 分类页标题里的身份词

身份词指 manufacturer、supplier、distributor、厂家、供应商、代理这类说明「我们是什么身份」的词。三家搜索引擎都没有要求标题写不写身份词，这是站点的写法约定。站点档案里已经定了规则的，按档案执行；没有定的，按下面的通用做法提建议，并请负责人确认后写进档案。

1. **两个条件都满足，才给某个分类页的标题加身份词：**
   - 这个品类的「品类 + manufacturer / supplier」类查询有需求证据：关键词工具有量，或搜索控制台持续有展示；
   - 口径文件登记了这个身份是事实：自己生产的品类才能写 manufacturer，代理的写 distributor 或按口径文件的说法。
2. **其他分类页**：标题写主题词加关键参数（如速率、等级、封装、防护等级），不加身份词。理由：
   - Google《影响标题链接》（2025-12-10）不建议在标题里重复样板文字，全站每个分类页都挂同一个身份词正是这种情况；
   - SearchPilot 2025-09 公布的单站标题实验里，多塞词没有可测的提升（单站实验，只作参考）；
   - Zyppy 统计约 61.6% 的标题会被 Google 改写，多出来的词不一定显示（行业研究）。
3. **身份不写进标题，不等于不写**：放在 H1 下一句、首段、描述里，按品类分别写（自产、代理、经销可以不同）。H1 只写主题词。
4. **系列页、选型页、型号页**的标题不加身份词，正文可以提一句。
5. **不并列两个身份词**（如「Manufacturer & Supplier」）。
6. **国内站**的身份写法更要按口径文件：有的站规定标题不写「厂家」「供应商」，首段写「我们提供什么」。
7. **按数据调整**（经验做法）：每季度看一次搜索控制台，某品类「品类 + manufacturer / supplier」查询持续有展示，再评估给它的标题加身份词。

本技能只在对照表「主题词位置」一格里记下「标题带 / 不带身份词，理由」，标题的具体文字交 seo-tdk-page-elements。
