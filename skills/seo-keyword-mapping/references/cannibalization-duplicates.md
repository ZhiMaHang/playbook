# 关键词内耗与重复页

步骤 6 用。先确认是不是真的，再选办法；删除放到最后。301、canonical、noindex、robots 的技术实现交 seo-audit-remediation。

## 1. 什么是内耗

**关键词内耗**（keyword cannibalization）：站内多个高度相似、意图相同的页面争同一组查询，互相分流，哪一页都排不好。这是业内说法，Google 文档里检索不到这个术语。不说「关键词蚕食」。

- Google 人员的说法（2025-09，媒体转述 2025-09-22）：搜索控制台只记录实际展示，理论上的排名谈不上内耗；三个本站页面同时出现，不会只因为「多于一个」就成问题；应减少不必要的重复，集中做强一个页面。
- Google 的相关机制（排名系统指南 2025-12-10）：站点多样性系统让同一网站在前列结果里通常不超过两条；去重系统避免无益的重复结果。
- 推论：同站两个网址同时排上，不一定是坏事。
- 别乱贴标签：「内耗」常被当成排名不好的万能解释，真正原因往往是页面不聚焦、内容单薄、近似重复或内链薄弱。

## 2. 初判

| 可能是内耗（业内信号，证据较弱） | 多半不是内耗（先排除） |
|---|---|
| 两页意图相同，内容大段重复 | 首页和分类页同时出现在「品牌 + 品类」词下 |
| 同一查询的主要排名网址在不同日期来回换 | 不同语言版本出现在各自的市场 |
| 两页都停在中后位，谁也上不去 | 改网址期间，新旧网址同时有展示 |
| 主题、标题、H1 几乎一样 | 技术文章接信息词，产品页接商业词：意图不同 |

## 3. 在搜索控制台里查

五步：
1. **选范围**：效果 → 搜索结果，日期选近 3 个月。
2. **筛查询**：精确匹配目标词，或用正则合并几种写法。
3. **看网页表**：记下有展示的网址，以及各自的展示、点击、平均排名。
4. **看时间**：按周比较，主要排名网址有没有来回换。
5. **反过来查**：按网页筛其中一个网址，看它还接住了哪些查询。

**统计口径**：
- 图表按资源汇总，同一网站多个结果只算一次展示；「网页」表按网页汇总，两边合计可能对不上，这是正常的（GSC 帮助）。
- 界面表格最多显示 1,000 行（GSC 博客 2022-10-19）；GSC 只记录实际展示过的网址，排得很后的看不到。

**先排除假象**：
- 语言版本（`/de/xxx/` 与英文版）、http 与 https、带不带斜杠、大小写；
- 同站两条同时在第一页：站点多样性允许，先看是否都满足需求；
- 改网址过渡期：旧网址和新网址同时有展示，是迁移，不是内耗（新旧合起来看）。

**补充工具**：
- `site:域名 "关键词"` 列出站内提到这个词的所有页面；
- GSC 查询分组（2025-10-27 推出）：把同一问题的不同写法合成一组；
- 国内站：百度「流量与关键词」只到域名层级（2018-07-27），不能按网址筛，要结合必应网站管理员工具和 `site:` 看。

**记录**：每个词一行：查询｜有展示的网址｜各自的展示、点击、排名｜按周看主要排名网址有没有换｜排除了哪些假象｜判断｜办法。表头见 assets/templates.md。

没有任何平台数据时，只能写「疑似」，并请用户导出数据；不建议合并、删除这类难撤回的动作。

## 4. 诊断决策树

判断前先收集：两页近 3 个月的展示、点击、排名；两页各接住了哪些查询（网页表反查）；两页的标题、H1、主要内容；两页的入链数（链接报告）；哪一页带来过询盘。

```
同一查询下有多个本站网址
└─ 问 1：是同一内容的不同网址吗？（参数、大小写、斜杠、新旧网址、语言版本）
   ├─ 是 → 技术重复：301 或规范网址；语言版本用 hreflang
   └─ 否 → 问 2：两页满足的是同一个意图吗？
           ├─ 不是 → 差异化：标题、H1、锚文本各管各的主题；或不处理
           └─ 是 → 问 3：弱的那一页还有独立价值吗？
                   ├─ 没有 → 有用内容并进强的一页，弱页 301
                   └─ 有 → 问 4：它需要单独出现在搜索结果里吗？
                           ├─ 需要 → 差异化，让两页主题分开
                           ├─ 不需要 → noindex，留给用户访问
                           └─ 只是参数、打印这类变体 → 规范网址
```

另外两种：两页都满足需求、都排得上 → 不处理、观察；内容无法挽救、也没有对应页可跳 → 删除（404 / 410），最后手段。

## 5. 六种办法

| 办法 | 什么时候用 | 怎么做 | 常见情形 |
|---|---|---|---|
| 合并 + 301 | 两页意图相同且都偏弱，或一页已没有独立价值 | 有用内容并进强的一页；旧网址 301；内链改指新页 | 改版后内容已并入新页的旧网址；两篇讲同一问题的旧文章 |
| 规范网址 | 近似重复，但要留给用户：参数版、打印版、规格变体 | 重复页声明规范网址；内链指向规范网址 | 带排序、跟踪参数的网址；打印版 |
| 差异化 | 两页服务不同意图 | 调整标题、H1、内链锚文本，各管各的主题 | 选型文章和分类页争同一个词 |
| noindex | 对用户有用，但不需要进搜索结果 | 加 noindex，页面照常可访问 | 站内搜索结果页、空标签页、测试页 |
| 不处理 | 两页都满足需求，都能排上 | 观察，不动 | 首页和分类页同在「品牌 + 品类」词下：先查数据再定 |
| 删除（404 / 410） | 内容无法挽救，也没有对应页可跳 | 返回 404 / 410，从站点地图和内链里移除 | 最后手段 |

依据：
- Google《合并重复网址》（2026-07-10）：跳转是强信号，文档按影响力排序时排第一；canonical 也是强信号，最终由 Google 决定；不要用 noindex 或 robots.txt 选规范网址。
- Google 核心更新文档（2025-12-10）：删除是最后手段。较差的用户提交内容可以先 noindex（Google 人员 2020 年说法，媒体转述，年份较早）。
- 百度《搜索引擎优化指南 2.0》：一个网页只对应一个网址，其他形式 301 到标准形式。
- 必应网站管理员指南：内容搬家要用跳转，不要拿 canonical 代替。

**牵连多的时候**：改栏目名会牵连多语言译文、程序按名称找栏目时，选影响最小的办法（比如只改标题和描述做差异化），但把遗留问题写下来，不当成已经解决。差异化做不完整（比如网址和内容对不上）也要写明。

## 6. 常见情形速查

| 情形 | 是不是内耗 / 重复 | 办法 | 理由 |
|---|---|---|---|
| 改版后的旧网址返回 200、规范网址指向自己，和新页讲同一件事 | 重复（旧网址） | 合并 + 301 到新页 | 旧页没有独立用途；跳转是强信号 |
| 首页和分类页都用同一个品类词 | 先查数据再判断 | 看展示落在哪页、是否轮换；对照表只指定分类页为承接页 | 意图不同时通常不算内耗 |
| 英文页和 `/de/` 页在同一查询下都有展示 | 不是 | 不处理；检查 hreflang 是否双向 | 语言版本面向不同市场 |
| 改网址当月，旧网址和新网址都有展示 | 不是 | 查 301、站点地图、内链是否已改；新旧合起来看数据 | 改网址的过渡期 |
| 后台给编辑分类用的子栏目都生成了可收录页面，内容相同，标题还和主页面相近 | 重复，且抢词 | 子栏目页 301 到对应主页面；主页面补进站点地图 | 没有独立内容 |
| 两页标题相同，但都有用途（如一个讲技术支持、一个是留言表单） | 标题重复 | 差异化：标题、H1、锚文本各管各的；或合并 + 301，说清会失去什么 | 都有用途时差异化影响较小 |
| 0 篇文章、也没有介绍的话题页 | 空聚合页 | noindex 或不生成 | 劲风算法打击空短聚合页 |
| 站内搜索结果页（带 `?q=`）被收录 | 站内搜索页 | noindex | 劲风算法打击站内搜索结果生成的页面 |
| 下级页正文大段照搬上级页 | 模板继承的重复 | 去重 + 写独有内容 + 原位置链回上级 | 重复内容影响体验、浪费抓取 |
| 分类页加 `?sort=price` 生成的排序网址 | 参数重复 | 规范网址指向不带参数的页，或 robots.txt 禁止抓取排序参数 | 排序不改变内容 |
| 两篇旧文章讲同一个选型问题，排名都在 20 名以后，轮流出现 | 内耗 | 合并到较强的一篇 + 301 | 意图相同、弱的一篇没有独立价值 |

## 7. 合并五步

1. **选留哪篇**：展示和点击多、外链多、网址更好的那篇。
2. **并入独有内容**：另一篇里有用的段落、数据、问答搬过来，去掉重复（正文改写交 seo-content-writing）。
3. **旧网址 301**：服务器端永久跳转；不用 noindex、robots.txt 选规范网址。
4. **改内链和站点地图**：站内链接直接指向保留的网址；站点地图只放保留的网址。
5. **看数据**：4–8 周后合计新旧网址的展示和点击，和合并前比（经验值）。

canonical 还是 301：两页都要留给用户访问，用 rel=canonical（强信号，最终由 Google 决定）；不需要旧页，用 301。

常见错误：合并后旧网址直接返回 404，外链和收藏都断了；只在新页加 canonical，旧页内容一点没动；跳转一层套一层，没有一步到位。

## 8. 重复页从哪来

重复页多半不是故意做的，先认出它从哪来：

| 来源 | 怎么产生 | 处理 |
|---|---|---|
| 模板继承 | 下级页沿用上级页的长篇板块，页面一多重复成片 | 去重，写独有内容（第 12 节） |
| 参数 | 测试、排序、筛选、跟踪参数生成新网址 | 测试页 noindex；排序、跟踪参数用规范网址；筛选见第 11 节 |
| 标签 / 话题 | 每个标签一页，文章少时几乎相同 | noindex 或不生成（第 10 节） |
| 站内搜索 | 搜索结果页被收录 | noindex |
| 自动生成 / 机翻 | 程序批量建页、自动翻译 | 删除或 301；停用这类程序（第 13 节） |
| 旧网址 / 子栏目 | 改版后旧页还能打开；后台栏目都生成了网页 | 301 到主页面 |
| 共用模板正文 | 每页大段相同的条款或说明，独有信息很少 | 补每页独有的信息（参数摘要、封装、应用、替代料） |

后台栏目是给编辑分类用的，不一定都要变成可收录的网页。没有独立内容的子栏目，通常不必生成独立网址；已经生成的，合并到主页面并 301。

## 9. 搜索引擎怎么对待重复

- **Google**：站内重复不违规；Google 把重复页聚成一组，自选规范网址，rel=canonical 只是提示（《规范化》2026-08-20）。但为操纵排名批量生成没有增值的页面，属于滥用规模化内容，包括抓取内容、经翻译等自动变换批量生成（垃圾政策 2026-08-28）。重复内容不属于垃圾违规，但影响体验、浪费抓取；首选 301，不能跳转再用 rel=canonical（《SEO 新手指南》2025-12-10）。
- **百度**：重复、主体空短、作弊的网页不收（《百度搜索的工作原理》2023-12-21）；劲风算法（2020-02）打击与站点领域、标题或标签不符的聚合页，站内搜索结果生成的静态页，空短或失效的聚合页。
- **必应**：大模型会把近似重复的网址归为一组，只选一个代表页（必应官方博客 2025-12-19），这对 AI 回答的引用同样适用；每个网址聚焦一个主题。

推论：重复页通常不会招来惩罚，代价是选不了哪一页被展示、抓取被浪费、每一页都做不强；批量造页则是垃圾政策点名的情形。先自己选好规范网址（301 或 canonical）。

搜索控制台「网页」报告里，「重复网页，用户未选定规范网页」「备用网页（有适当的规范标记）」「Google 选择的规范网页与用户指定的不同」三类状态，是查重复的线索；后一类常见原因是 canonical 写错、页面过于相似、本地化页面缺 hreflang（Google《修复规范化问题》2026-08-21），修法交 seo-audit-remediation。

## 10. 标签页、话题页、站内搜索页

这些都是聚合页：本身没有正文，内容来自别的页面。

- Google 人员（2021，媒体转述，年份较早）：标签本身不一定有助于排名，只是在站内多出一些链接和页面。「标签过多会产生大量单薄的近似页」是业内观点，证据较弱。
- 百度劲风算法（2020-02）明确打击站内搜索结果生成的静态页、空短或失效的聚合页。推论：面向百度的中文站，标签页、站内搜索页、空筛选页的风险比海外站高。

**判断**（推论）：聚合页有自己的介绍文字、条目够多，读者在这里能完成一件事（比如按品类找全文章），才开放收录；否则 noindex 或不生成。

想把站内搜索的零结果热词做成独立页面（如「求购型号」页）的，页面要有真实内容（说明、相关的在库型号、询价入口），空页容易落进劲风打击的范围。

**怎么查**（经验做法）：`site:` 搜路径（如 `site:example.com/news/topic/`）看收录了哪些；打开 0 篇的话题页，看源代码有没有 noindex。「设了」不等于「真的输出了」，要自己核。

## 11. 筛选页

筛选（分面）导航每多一个条件就多一批网址，组合几乎无限，爬虫在这些网址上过度抓取，新页面被发现得更慢（Google《管理分面导航网址的抓取》2025-12-18）。先问业务：这个组合有没有人搜、有没有独有内容。

| 这个筛选组合需要被搜到吗 | 做法 |
|---|---|
| 不需要 | robots.txt 禁止抓取筛选参数，放行一个不带筛选的完整列表页；canonical、nofollow 的长期效果一般不如 robots.txt |
| 需要（有人搜这个组合） | 做成固定的分类页或选型页；路径里的筛选顺序固定；没有结果的组合返回 404 |

- 预设好条件的选型页就是「做成了固定页」，但仍要过 site-structure.md 第 5 节的门槛：预设条件筛不出料号的页面不该在线。
- 面向百度的站，没有结果的筛选页容易落进劲风打击的空聚合页（推论），筛选参数默认不收录；动态网址参数要少，不放会话 ID。
- 技术实现交 seo-audit-remediation。

## 12. 模板继承的去重四步

依据：Google《SEO 新手指南》对重复内容的说明（影响体验、浪费抓取），《创建有用的内容》（提供原创、有实质价值的信息）。

1. **删照搬的**：下级页不整段输出上级页的介绍、说明和通用问答。
2. **写独有的**：本系列的参数差异、应用、资料、替代候选、真实问答。目的是把读者要的信息写全，不是为放词扩写，字数不是指标（写作交 seo-content-writing）。
3. **没数据先不上线**：没有真实型号、没有独有内容的页，先补数据或并入上级页。
4. **链回上级**：原来照搬板块的位置，放一个短板块链回上级页。

重合率、独有字数这类内部检查口径只用来找问题，不是效果；前后对比要用同一口径（同一批页、同一种算法），口径不同的两个数不能比。为放词扩写后主题词组密度很高的，按关键词堆砌逐页通读。效果看 4–8 周后的平台数据，要有冻结基线。

## 13. 自动建页和机翻

会自动建页的程序（跨站同步、批量导入、按词生成页面）最容易成片地造出重复页和低质页：比如同步程序按网址匹配两站的对应页，网址对不上就新建一页机翻内容，和正版页并存、抢同一组词。

- 这同时踩两条线：重复（和正版页抢词），质量（经翻译等自动变换批量生成、几乎不提供价值，是滥用规模化内容的例子）。
- 这类页面不报错、照样能打开，只能专门去查。识别（四项都对上才算，免得误删正版页）：没有产品、没有子栏目；SEO 字段像机翻（全大写、直译）；后台没有和对应站栏目的关联；和正版页主题相同。
- 处理：删除或 301 到正版页；停用这类自动建页。两站内容要一致时，由人在各自后台录入。
- 教训（推论）：会自动建页的程序，上线前先想清楚「对不上时怎么办」：宁可报错停下，也不要自动新建页面。
