# 内链与锚文本

步骤 5 用。内链决定搜索引擎能发现哪些页面、认为哪些页面重要；锚文本告诉它被链的页面讲什么。

## 1. 什么样的链接能被抓取

依据：Google《链接的最佳做法》（2025-12-10）。

| 写法 | 能不能可靠抓取 |
|---|---|
| `<a href="/ethernet-transformers/">Ethernet transformers</a>` | 能 |
| 用 JavaScript 插入的标准 `<a href>` | 能（要渲染后才看得到，不渲染的爬虫看不到） |
| `<a onclick="goTo()">…</a>`（没有 href） | 不能 |
| `<span href="/ethernet-transformers/">` | 不能 |
| 只靠点击事件跳转的按钮 | 不能 |
| 图片链接 | 能；alt 就是锚文本，alt 为空等于没有锚文本 |

- 在乎的每个页面都至少要有一个站内页面链向它。
- 每页链接数没有理想值，但过多很可能有问题。
- Google 生成结果页的标题链接时，会参考 H1、og:title 和站内外指向该页的锚文本（Google《影响标题链接》2025-12-10），锚文本写得好对标题也有帮助。

**验收**：看源代码或渲染后的 HTML，确认入口是真正的 `<a href="…">`；把锚文本单独念一遍，能听懂它链向什么。

## 2. 内链有什么用：证据分级

| 来源 | 说法 | 怎么用 |
|---|---|---|
| Google 排名系统指南（2025-12-10） | 链接分析和 PageRank 仍是核心排名系统的一部分 | 官方依据 |
| Google《搜索的运作方式》 | 发现新网址主要靠已知页面上的链接和站点地图 | 官方依据 |
| Google 人员发言（2022，媒体转述） | 内链是引导 Google 和访客找到你认为重要的页面的最主要手段之一；原话没有说内链本身是排名因素 | 参考 |
| 百度《网站优化》（2019-03-30）、《搜索引擎优化指南 2.0》 | 内链形成的逻辑结构比目录更受关注；首页—频道—内容页互链 | 官方依据 |
| Zyppy 内链研究（约 1,800 个网站、2,300 万条内链，2026-02-23 更新） | 内链 0–4 条的网址平均约 2 次点击，40–44 条约为它的 4 倍，超过 45–50 条反而下降；锚文本种类越多点击越多；作者说明是相关性分析，不能证明因果 | 只当方向，不当指标，不去凑条数 |

结论（推论）：内链先解决「能不能被发现」，再表达「哪页更重要」；不要指望靠堆内链把排名推上去。

## 3. 内链放在哪

| 位置 | 作用 | 写法 |
|---|---|---|
| 导航、下拉、面包屑 | 结构链接，全站保底 | 见 site-structure.md 第 9、10 节 |
| 正文上下文链接 | 带上下文，最能传达主题 | 锚文本写目标页主题，放在相关的句子里；链接前后的文字也有作用 |
| 相关产品 / 推荐区块 | 同级、上下级互通 | 按相关性挑，不全站一样 |
| 列表与分页 | 让大量型号页被发现 | 分页用普通链接，不只靠「加载更多」 |

**推荐区块怎么挑**（建议做法）：
- 分类页推荐同主题的选型、对照、故障文章；
- 系列页（四级页）链回上级分类页；
- 同级品类之间按选型关系互链（经常一起选的两类产品互相链接）。

**选型表、资料列表**：型号页常靠选型表链过去，资料常靠下载列表链过去。要确认它们在源代码或渲染后是真正可抓取的链接：数据放在隐藏的文本框里、列表靠接口加载而接口被 robots.txt 禁止抓取，搜索引擎都看不到这些链接（技术处理交 seo-audit-remediation）。

## 4. 锚文本

规则（Google《链接的最佳做法》）：描述性、简洁，和所在页、目标页都相关；单独读也能看懂；不硬塞关键词，堆砌违反垃圾政策；不把一串链接挨着连在一起。

| 场景 | 不好 | 好 | 为什么 |
|---|---|---|---|
| 文章链到分类页 | click here / 点击这里 | push-pull transformers | 单独读也能看懂 |
| 首页链到分类页 | Read more | Ethernet transformers for PoE switches | 说清目标页讲什么 |
| 多处链到同一页 | 每处都是同一个词 | 主题词和同义叫法轮换：ethernet transformers、LAN transformers、ethernet magnetics | 自然、不堆砌 |
| 对照文章链到候选型号 | pin-to-pin replacement、best alternative | 写候选型号本身（料号） | 最高级和未经确认的兼容说法通常是口径文件禁用的 |
| 中文站链到分类页 | 网络变压器厂家网络变压器价格 | 网络变压器选型 | 拼成一串是堆砌 |
| 图片链接 | alt 为空 | alt 写图片内容，如「带灯 RJ45 网口实物图」 | alt 就是锚文本 |

**口径红线**：锚文本、导航名也是页面上的文字，同样守本站的口径文件。客户会搜「料号 + pin to pin」「源头厂家」，不等于我们可以这样写。口径文件里禁用的说法（最高级、未经确认的直接替换、未登记的身份），写在锚文本里一样违规。

**锚文本也是一种布局**：别人的主题词只作锚文本，链到它的承接页；同义叫法作锚文本，链回分类页；同一个主题词作锚文本时，只链向它唯一的承接页，不要一会儿链 A、一会儿链 B。

## 5. 内链计划

五步：

1. **选目标页**：对照表里的承接页，加上排在第 4–20 名的机会词所在的页面（离前排近，见效通常较快）。
2. **找来源页**：同主题、本身有展示的页面。
   - `site:域名 "词"` 列出站内提到这个词的页面；
   - 搜索控制台效果报告 → 网页，按展示排序，找流量高的同主题页；
   - 先挑同主题、在搜索控制台里有展示的文章和上级页。
3. **定锚文本**：目标页的主题词或它的自然变体、同义叫法。
4. **定位置**：正文里第一次提到这个词的地方，或文末的相关资料区。
5. **记录复查**：4–8 周后在搜索控制台按查询筛这个目标词，看展示和排名的变化，记进计划表。

计划表每行一条链接：目标页｜目标词（当前排名，时间范围）｜来源页（展示，时间范围）｜锚文本｜位置｜理由｜状态｜复查日期｜复查结果。表头见 assets/templates.md。

- 「状态」只写事实：建议、已排期、已上线（日期）。没上线的不写成「已做」。
- 样本太小（目标词只有一两次展示）的，照做但在理由里注明「数据不足以判断效果」。
- 计划里的链接多半不用写新内容，只是把已有页面连起来，投入相对小，适合先做。

## 6. 内链体检清单

逐项查，发现的写进站点结构图或整改清单，附日期：

1. 重点页有没有至少 1 个站内文字链接；孤岛页列出来。
2. 同级品类之间有没有互链。
3. 推荐区块是不是全站同一组链接。
4. 首页、文章有没有链到分类页和型号页。
5. 首页链接总数是否过多（多到每个链接的分量很小、看不出重点）：大菜单分组精简。
6. 模板有没有把链接渲染成纯文字（比如加粗、Markdown 里的链接显示成原文），导致链接丢失。
7. 列表、选型表是不是靠接口或脚本加载、搜索引擎看不到。
8. 小语种页面有没有链到不存在的同语言页（404）。
9. 内链是不是指向会跳转的旧网址：站内链接应直接指向最终网址。
10. 笼统锚文本（「点击这里」「更多」「→」）有多少。
11. 同一个主题词作锚文本时，是不是只链向它唯一的承接页。

`scripts/click_depth.mjs` 的输出能直接回答第 1、2（看入链来源）、5、9、10 项：每页的入链数、指向跳转网址的链接、每个目标页收到的锚文本及次数、笼统锚文本清单。
