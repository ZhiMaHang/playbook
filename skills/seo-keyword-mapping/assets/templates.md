# 交付模板

表格软件里一张表一个工作表（sheet），或各存一个 CSV（UTF-8）。文件名带站点和日期，例如 `example_对照表_20261105.xlsx`；每次另存新版本，旧版本放进「历史版本」，不覆盖。

示例行是虚构的，只说明每格写什么。所有数字写来源、日期和时间范围；没有的写「未知」。

## 1. 关键词—页面对照表（落地版）

按页面组织：每个承接页一行，「页面网址」只填一个网址，同一个主题词只出现在一行。没有承接页的词也占一行，网址写「待建：页面类型」或「不做」。

前 7 列是研究阶段的对照表；中间 5 列是本技能补的落地列；「首页用法」只在首页也提到这个词时填。

| 列 | 写什么 | 示例 |
|---|---|---|
| 页面网址 | 承接页的规范网址；或「待建：页面类型」「不做」 | `/waterproof-rj45-connectors/` |
| 主题词 | 一个 | `waterproof rj45 connector` |
| 同义叫法与辅助词 | 同义叫法注明「各提一次」；辅助词不设个数 | `rj45 panel mount`、`bulkhead rj45`（辅助词） |
| 搜索量与来源 | 工具估算值 + 工具、国家、日期；没有写「未知」 | 400 / 月（虚构），关键词工具，美国，查询日期 |
| 现在排第几 | 搜索控制台平均排名，写清时间范围；没有排名写「无」 | 第 18 位（虚构，近 28 天） |
| 意图 · 细类 | 主题词的意图 | 商业 · 产品浏览 |
| 页面类型 / 层级 | 按意图 × 属性定；第几层 | 分类页 · 第 3 层 |
| 上级页 | 面包屑里的上一级 | `/rj45-connectors/` |
| 主题词位置 | 标题、H1、首段、导航名、面包屑逐项打勾；标题带不带身份词及理由 | 标题 ✓ H1 ✓ 首段 ✗ 导航名 ✓ 面包屑 ✓；标题不带身份词（无「品类 + manufacturer」需求证据） |
| 入链来源 | 哪些页面、用什么锚文本链过来 | 首页导语：Waterproof panel-mount RJ45 connectors；`/blog/outdoor-ethernet-wiring/`：waterproof RJ45 connectors |
| 链出到 | 下级页、型号页、相关文章 | 3 个代表型号页；`/blog/ip67-connector-selection/` |
| 首页用法 | 首页怎么提到这个词（只写用法，不另指承接页） | 产品卡片名 + 指向本页的链接 |
| 下一步 | 具体到改哪一处；「不做」「待建」写原因 | 首段补主题词；补 2 个入链 |
| 负责人 | 角色或人 | 站长 |
| 复查日期 | 上线后 4–8 周 | 上线日 + 6 周 |
| 状态 | 已核实 / 推定 / 待核同义 / 待口径确认 | 推定（同义未核结果页） |

不设人群列。要分析「谁在搜」，在备注里从词出发写：可能谁在搜 → 痛点 → 我们的方案。

`scripts/map_check.mjs` 认这些列名：网址列「页面网址 / 页面 / 承接页 / url / page」，主题词列「主题词 / 主词 / primary keyword / topic」，原因列「下一步 / 原因 / 备注」。

## 4. 内耗检查表

| 查询 | 有展示的网址 | 各自展示 / 点击 / 排名（时间范围） | 按周主要排名网址是否轮换 | 排除了哪些假象 | 判断 | 办法 | 依据 | 负责人 | 复查日期 |
|---|---|---|---|---|---|---|---|---|---|
| | | | | 语言版本 / 斜杠 / 改网址过渡 / 意图不同 | 已核实内耗 / 疑似 / 不是 | 合并 + 301 / 规范网址 / 差异化 / noindex / 不处理 / 删除 | | | |

**处理方案**（每组一份）：
1. 现状数据：查询、网址、展示 / 点击 / 排名，带时间范围和来源；
2. 判断：按决策树哪一问得出结论；
3. 办法：具体改哪里（代码模板、后台字段、服务器配置、内容）；
4. 风险：会失去什么（排名波动、译文牵连、程序依赖）；
5. 回滚：出事怎么撤；
6. 复查：几周后看什么数，什么结果算有效；
7. 待负责人拍板：是 / 否。

## 5. 301 对照表

| 旧网址 | 新网址 | 状态码 | 一次到 200 | 内链已改 | 站点地图已改 | hreflang 已改 | 1 周复查 | 1 个月复查 |
|---|---|---|---|---|---|---|---|---|
| 旧网址 A | 新网址 A′ | 301 | ✓ | ✓ | ✓ | ✓ | | |
| 旧网址 C | 没有对应新页 → 最相关的上级页 | 301 | ✓ | ✓ | ✓ | — | | |

不合格要返工：302、多次跳转、404、内链未改、站点地图里还是旧网址。交技术执行前由负责人确认。
