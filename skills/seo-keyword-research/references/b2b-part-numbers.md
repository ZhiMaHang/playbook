# B2B 元器件与工业品：料号词、竞品料号、参数词、找厂家类词

元器件、工业品的关键词有自己的特点：工程师常按参数和料号搜，采购常拿着 BOM 搜，料号结果页常被分销商占满，manufacturer、supplier 这类词量很小。

## 1. 买家怎么搜（看方向的数据）

| 数据 | 出处 |
|---|---|
| 工程师查信息时 77% 更常用搜索引擎，8% 更常用生成式 AI | TREW Marketing × GlobalSpec，2026，n=753 |
| 联系销售前平均已在线完成约 62% 的购买流程 | 同上，n=709 |
| 79% 把规格书列为有价值的内容，各类内容中最高 | TREW，2025，n=1,018（多选题） |
| 66% 把选型 / 参数搜索列为有用的工具，各类工具中最高 | TREW，2025，n=1,009（多选题） |
| 分销商平台用户查料号是为了查库存 88%、比价 76%、找替代件 51% | Altium《2024 Octopart 用户调研》，2025-03-25，n=584 |

样本偏差：TREW 2026 受访者 72% 在 56 岁以上、43% 在美洲，电子元器件和半导体只占 16%；Octopart 受访者本来就偏向查库存、比价。用来判断方向，不能直接套到国内买家。

含义（推断）：带料号、参数的词，以及查规格书、找替代的词，通常离询盘更近。

## 2. 料号词的写法

料号（part number，也叫 MPN）一般分几段：品牌 / 系列前缀 + 产品线 + 规格代码 + 包装后缀（例如 TR 表示编带）。

- 采购常从 BOM 复制完整料号（含后缀）来搜；工程师常搜基础料号或「料号 + datasheet」（常见做法的归纳，没有统计）。
- **关键词表里**：规范写法按原厂规格书（通常大写、不带空格）；不带包装后缀的基础料号记在备注，两种搜法都要能对上。
- **页面上**（交给 TDK、正文技能）：标题和 H1 用原厂标准写法；正文或参数表写出基础料号；不堆空格、连字符的变体，搜索引擎一般能识别（经验判断，可在后台核对）。
- **站内搜索**：要容错，忽略大小写、空格、连字符，支持只输前半段。站内搜索零结果、热词是具体料号，说明需求在，问题出在写法匹配或承接页面上。
- 同一型号在站内有几种写法（带空格、带连字符）、页面之间对不上，是平台站常见问题，先统一写法再做词表。

## 3. 料号结果页：不硬抢裸料号，抢「料号 + 意图」

分销商每个料号一页，带库存、价格、参数、规格书、CAD 模型，正好满足查库存、比价的需求，所以裸料号的结果页常被分销商、现货商、EDA 模型站占满，原厂官网都不一定进前 10。

原厂和中小站的打法：
- **抢「料号 + 意图」**：料号 + datasheet（信息 · 参数资料）、料号 + equivalent（商业 · 替代查询）、料号 + footprint；
- **铺进分销商目录**：让分销商的料号页替你接住裸料号的流量；
- **学分销商的字段**：类目名和参数字段是现成的买家词表参考。

关键词表里，裸料号标「未带意图修饰」，可赢性一般给 0–1；「料号 + 意图」按对应细类打分。

页面要做好的五件事（交给 seo-content-writing、seo-audit-remediation 落地）：规格做成 HTML、PDF 作附件；参数写成网页文字；做替代对照页；Product 结构化数据写 mpn、sku；补齐购买信息（授权分销商、样品、合规文件）。

## 4. 竞品料号

采购和工程师会直接搜别家料号。单个量小（美国月搜几十次一个，KE，2026-10），合起来可观；「料号 + equivalent」的写法在工具里几乎都是 0，但意图明确。

- 裸的别家料号 = 未带意图修饰；加 equivalent、alternative、cross reference、替代 = 商业 · 替代查询；加 datasheet = 信息 · 参数资料，本站没有它的型号页时由替代对照页承接。
- 结果页前排如果没有页面认真回答替代问题，就是机会。
- 广告里竞品料号贵、不转化，原因交给投放同事查；对 SEO 它说明有人搜。
- 承接：一篇认真做参数对照的文章或对照页，写清哪些参数一致、哪些不同、建议用样品验证。
- 在关键词表里统计：有量的竞品料号多少个、合计多少，已有对照页的多少、缺多少，缺的按量排进动作。

**口径**：替代怎么写以本站口径文件为准。常见的约束是不泛称 pin-to-pin、drop-in、direct replacement、fully compatible，只写候选型号、用样品验证。客户这样搜，不等于页面可以这样承诺。

**红线**：不给每个竞品料号自动生成只换型号的「XXX equivalent」空页，属于滥用规模化内容（Google 垃圾政策，2026-08-28）。判断三问：去掉型号名，这一页和同类页还剩多少不同？有没有别处找不到的信息（参数、图纸、对照、样品途径）？不考虑搜索引擎，我们还会做这一页吗？

## 5. 参数词

工程师在需求构建阶段常把参数写进搜索词：速率、端口数、PoE 等级、安装方向、是否带灯、隔离电压、工作温度、封装。

| 参数类型 | 常见写法 | 例子（美国月搜，KE，2026-10） |
|---|---|---|
| 速率 | 10/100、1000base-t、2.5g、10g | 1000base-t transformer（10） |
| PoE | poe、poe+、poe++、802.3bt | poe transformer（40） |
| 结构 | right angle、tab up、tab down、1x4 | right angle rj45 connector（70） |
| 指示灯 | with led | rj45 with led（20） |
| 安装与封装 | smd、through hole、pcb | pcb rj45 connector（40） |
| 环境 | industrial、-40 to 85 | industrial rj45 connector（70） |

- 意图多是商业 · 产品浏览，也有信息 · 选型方法。
- 单个量小，合起来可观（推断）。
- 承接：**系列 / 选型页**，一个系列一页，配可筛选的参数表，正文用文字写主要选型维度和代表料号。
- 不为每种参数组合生成可收录的筛选页：组合数爆炸、页面高度重复、浪费抓取资源，还有规模化内容风险（技术处理交 seo-audit-remediation）。

## 6. 找厂家、找供应渠道类词

manufacturer、factory 是找厂家；supplier、distributor、wholesale 是找供应渠道。

- 量常常很小：例如 rj45 connector manufacturer 30、lan transformer manufacturer 10，factory、OEM、wholesale 类修饰词几乎都是 0（KE 美国，2026-10-12～13）。**查了再定，不要想当然**。
- 工具为 0 的，看后台：GSC 里可能已有展示（例如「品类 + supplier」几十次展示）。
- B2B 的 AI 提示词里常见「manufacturers of …」这类找厂家句式（Ahrefs 提示词选择指南，2026），这类问法补进问题集。

**身份词的研究结论怎么给**（标题怎么写交 seo-tdk-page-elements；以下是通用规则，站点的具体规定写进站点档案）：
- 搜索引擎没有要求标题写不写身份词（manufacturer、supplier、distributor、厂家、代理），写不写是站点自己的规定。
- 身份词要同时满足两条才考虑进标题：**身份属实**（在本站口径文件里，例如只有自产品类能写 manufacturer）；**有需求证据**（「品类 + 身份词」在工具里查得到量，或在后台持续有展示）。通常只有少数旗舰品类满足。
- 其他分类页标题写主题词 + 关键参数，身份写在 H1 下一句、首段、描述和全站 Organization 结构化数据里；系列 / 选型页标题放系列名或产品名，不加身份词。理由：Google 不建议标题重复样板文字（《Influencing your title links》，2025-12-10）；分类页标题追加重复关键词变体没有可测提升（SearchPilot，2025-09，单站实验）；Google 改写约 61.6% 的标题（Zyppy，2022 年一季度），多塞的词不一定显示。
- 不要把 Manufacturer 和 Supplier 并列塞进同一个标题。
- 每季度看一次后台：某品类「品类 + manufacturer / supplier」类查询持续有展示，再考虑给它的标题加身份词（经验做法）。

在关键词研究表里：每个品类记一行「品类 + manufacturer」「品类 + supplier」（中文站「品类 + 厂家」「品类 + 供应商」），写量、后台展示和口径是否允许，在「动作」里给结论：可进标题 / 只写正文 / 不写。

## 7. 平台站（撮合别人的货）

- 重点在海量型号页和站内搜索需求：型号写法统一，页面不能只有型号；
- 站内零结果搜索词就是需求信号，统计热词、按料号聚合，作为补货和建页的依据；
- 同样守规模化内容红线：没有独立信息的型号页不要批量放出。
