# 候选词来源

候选词越贴近买家原话越好。来源不写死个数，按分组记，新的来源出现了就加一组。

工具菜单、额度、价格会改版，下面的操作写的是截至 2026-10 的样子，以后台为准，每季度复核一次。

## 1. 来源总览

| # | 分组 | 具体来源 | 能拿到什么 | 可信度 |
|---|---|---|---|---|
| 1 | 自有数据 | GSC、必应、百度后台；站内搜索；询盘；销售与 FAE | 真实搜索词、排名；客户原话和料号 | 最高 |
| 2 | 广告数据 | Google Ads、百度营销、微软广告的搜索词报告 | 真实搜索词，带花费和转化 | 高（只作参考） |
| 3 | 关键词工具 | Keywords Everywhere、Google 关键词规划师、百度营销关键词规划师、必应关键词研究 | 搜索量、出价、相关词 | 中（估算值） |

| 6 | B2B 平台与电商 | B2B 采购平台和电商站内搜索 | 平台买家的说法 | 中（平台口径） |

自有数据看「已经在发生什么」，其余各组找「还没覆盖的需求」。平台、社区和 AI 来的词，都回搜索引擎查量、看结果页，确认搜索引擎里也有这个需求再用。

## 2. 自有数据：搜索后台

### GSC

导出：效果 → 搜索结果 → 日期选近 3 个月 → 勾选点击、展示、点击率、平均排名 → 先按国家筛选 → 查询标签页 → 导出。

- 界面上限 1,000 行；更多数据用 API 或 Looker Studio（每天每站每种搜索类型 5 万行）。
- 数据保留 16 个月，通常延迟 2–3 天。
- 2025-10 推出查询分组（同一问题的不同写法合成一组），可作 Google 视角的聚类参照；品牌词筛选 2025-11 推出、2026-03 起向符合条件的站开放。
- 平均排名是每个查询取本站最靠前的位置再平均。

按意图粗筛的正则（查询 → 自定义（正则表达式），RE2 语法；整理自 Google Search Central 2021-04-07、2021-06-02）：

| 用途 | 正则 |
|---|---|
| 信息 · 问句 | `^(what\|how\|why\|which\|when)\b` |
| 信息 · 参数资料 | `datasheet\|pdf\|pinout\|footprint\|3d model` |
| 对比、替代（筛出后还要再分） | `\b(vs\|alternative\|equivalent\|replacement)\b` |
| 商业 · 询价找厂 | `\b(price\|buy\|supplier\|manufacturer\|sample)\b` |
| 排除 DIY（选「不匹配」） | `crimp\|wiring\|tool\|cable\|tester` |

（表里的 `\|` 是表格转义，粘进 GSC 时写成 `|`。）先排除再统计，DIY 流量就不会掩盖产品词的真实表现。正则只看词面，结果要抽查。

**GSC 的三个局限：**
- **匿名查询**：搜的人太少的查询不显示原文。Ahrefs 统计匿名查询平均约占点击的 47%（2026-02-11）；B2B 小站的比例可能更高。先算一下本站的覆盖率（可见查询的点击合计 ÷ 同期网页维度的总点击），写进结论。查询层面的数字只能看结构，不能当全量。
- **只看得到有展示的词**：没排上的需求，后台里没有。
- **数据断点**：2025-09 中旬 Google 停用 num=100 参数后，很多站展示量骤降、平均排名「变好」，跨这个时间点不能直接比。

分析前先剔除机器查询、AI 工具的模板化长问句（单列，见 `ai-question-set.md`）、找联系方式的垃圾查询。

### 必应网站管理员工具

「搜索效果」：按关键词、页面、国家、设备看展示、点击、点击率、平均排名，最长 16 个月（必应博客 2025-03-18）。国内站最完整的词数据常在这里。关键词和页面明细只覆盖网页结果；2023-03-24 起扩源，跨这天对比要注意断点。

### 百度搜索资源平台

「流量与关键词」：自然结果的展现、点击、点击率、平均排名，电脑端和移动端分开；只到域名层级，不能按网址筛选。百度从 2015 年起不在来源网址里带关键词，看百度搜索词只能靠它。

## 3. 广告搜索词报告

投广告时平台告诉你用户实际搜了什么触发了广告。它是真实搜索，还带花费和转化。

- 位置：Google Ads 广告系列 → 洞察和报告 → 搜索字词；百度营销、微软广告：报告 → 搜索词报告。
- 每周导出一次，和投放同事共用一张表；SEO 另加一列「自然搜索怎么用」。

SEO 拿来做什么（只作参考）：
- 看说法：买家实际怎么写料号、品类、问题；
- 看量级：哪些词真有人搜；
- 看意图线索：带不带询价、找厂家修饰，哪些词带来询盘；有转化的词在自然搜索里也值得重点看。

不要这样用：
- 广告不转化，可能是出价、落地页、匹配方式的问题，不等于不值得做 SEO；
- 广告的否定词只留在广告里，SEO 不照搬。SEO 剔除一个词只看卖不卖、意图对不对；
- 竞品料号在广告里贵、没转化，原因交给投放同事查；对 SEO，它说明这些料号确实有人搜。

## 4. 站内搜索、询盘、销售与 FAE

- **站内搜索**：已经进站的访客的真实需求。零结果的词说明要么叫法不对、要么产品线有缺口；平台站的零结果热词（多是具体料号）是需求信号，可以做成需求聚合。统计前剔除错拼和无关搜索。
  - GA4 开法：管理 → 数据流 → 增强型衡量 → 打开「网站搜索」，确认本站搜索网址里的参数名（如 q、s、keyword）填进设置；报告里看 view_search_results 事件的搜索词。
- **询盘原文**：每月收集一次，统计出现的料号、数量、应用、竞品型号、认证要求。邮件询盘也要算：59% 的技术买家第一次联系首选邮件（TREW Marketing × GlobalSpec，2026，样本以欧美工程师为主），只看表单可能漏掉一大半（推断）。
- **FAE 工单**：客户怎么描述问题、拿哪个料号来问替代。
- 客户说「pin to pin 替代」是客户的需求，页面上仍按本站口径写。

工具里没有的料号、问法、认证要求，往往只在这里找得到。

## 5. 关键词工具

| 工具 | 用法 | 注意 |
|---|---|---|
| Keywords Everywhere（KE） | 在 Google 结果页、GSC 旁显示搜索量、点击单价、竞争度、12 个月趋势；Bulk Keyword Data 批量查，选国家和货币；能查域名排名词 | 按积分计费，一个词一个积分，零量词也扣；查之前先清洗去重。美国数据来自 Google 关键词规划师，同样合并近似写法。**没有中国数据**：纯中文词按全球统计显示 0（2026-10-21 核对），中英混写的词只算拉丁字母部分 |
| Google 关键词规划师（GKP） | 需要 Google Ads 账户和账单信息；「发现新关键字」输入词或竞品网址拿相关词；「获取搜索量和预测」粘贴词表看月均量和出价区间 | 过去 12 个月平均、含近似变体、默认不区分语言（要手动设）；投放少的账户只给区间（如 100–1K）。依据：Google Ads 帮助 3022575、7337243（2026-10 访问） |
| 必应关键词研究 | 免费；按国家、语言、设备筛选，近 6 个月内任选时段；推荐词分相关词、问句词、近 30 天新发现词；顺带列出种子词前 10 名网址 | 「新发现」是近 30 天才被判定为相关的词，不等于新出现的搜索 |
| 百度营销关键词规划师 | 见 `engines-languages.md` | 需要企业的百度营销账户 |
| 付费中文工具（5118、爱站等） | 挖下拉词、长尾、竞品排名词 | 估算方法不公开，「指数」「权重」是工具厂商自己的模型，不是搜索引擎指标，只用来扩词、分组。爱站只收「带指数」的词，低频 B2B 词常查不到 |
| 综合平台（Semrush、Ahrefs 等） | 词库更大，能看竞品排名词、难度、聚类 | 见第 7 节 |

省额度：先清洗去重、去掉剔除词，再批量查量；同一批词一个季度内不重复查；记下花了多少额度。

## 6. 搜索引擎联想

- **下拉联想**：来自真实搜索，但 Google 明确说它不是热度排行（Google 搜索帮助 7368877），不能用来比大小。
- **字母扩展**：种子词后依次加空格和 a–z，记下每次的联想。
- **「其他人还问了」**：找一个主题下的子问题，点开会继续展开；AlsoAsked 这类工具能画成问题树。
- **相关搜索**：结果页底部，反映搜索引擎认为相关的说法。
- **只看论坛**：Google 网址末尾加 `&udm=18`。
- 百度的下拉框、相关搜索、「大家还在搜」用法相同。

以上都用无痕窗口、目标市场设置；拿到的词都要再查量、看结果页。不要刷下拉、刷点击：百度惊雷算法打击这类行为，B2B 是高发行业，严重的永久封禁。

## 7. 竞品与分销商

搜索上的竞争对手是和我们抢结果页位置的网站，不一定是生意上的对手。拿 5–10 个种子词搜一遍就知道是谁。

| 对手类型 | 我们学什么 |
|---|---|
| 原厂 | 系列命名、对照页、选型内容 |
| 分销商 / 平台 | 类目名、参数字段；不硬抢料号第一 |
| 内容站 / 论坛 | 工程师在问什么问题 |

- **分销商类目名和参数字段**：去大分销商的类目页和左侧筛选栏看。类目名贴近工程师的检索习惯（推断），是主题词的候选；参数字段（速率、PoE、方向、带灯、温度等）是系列页的筛选项和参数词。
- **对手站**：看导航、类目名、页面标题和 sitemap.xml。
- **看竞品要看它排的是什么词，不只看总流量**：同行在布线教程词上的流量再大，也带不来元器件询盘。

**查对手的排名词（Semrush，截至 2026-10，依据 Semrush 知识库 2026-10-26 查阅）：**
1. Organic Rankings（原名 Organic Research）：输入竞品域名，数据库选目标国家 → Positions 报告；按排名区间、搜索量、KD、Intent 筛选，导出。
2. Keyword Gap：第一栏填本站，后面填竞品（最多 5 个域名）。
3. 看 Missing（竞品都有、我们没有）、Weak（我们排在所有竞品后面）、Untapped（至少一家有、我们没有）。

Ahrefs 是同类付费工具（Site Explorer 的 Organic keywords、Content Gap）。

**没有付费工具时：**
- 关键词规划师「从网站入手」（Start with a website）：输入竞品网址，拿到和该网站内容相关的词。注意这不是对方的排名词（Google Ads 帮助 7337243）。
- KE 域名关键词：能查对方排名的词，按积分计费。
- 手工：用种子词搜，记下前 10 名的对手和它们的类目名、标题。

**差距词拿到以后**：先剔除不卖的、意图不对的 → 回搜索引擎看结果页 → 按意图归类 → 进打分。不能直接整批进表。

## 8. B2B 平台与电商

买家也在 B2B 采购平台和电商站内搜。

- 在平台搜索框输入品类词，记下下拉联想；看搜索结果页上的相关搜索、类目名、筛选项里的说法；来源一栏写平台名和日期。具体有哪些模块以平台页面为准。
- 亚马逊 Brand Analytics 报表只对加入 Brand Registry 的品牌方开放（Amazon Brand Analytics 介绍页，2026-10-26 查阅）。

平台词的两个特点：
- **平台口径**：量不能和搜索引擎、KE、规划师的数字比，也不能相加；
- 常带 factory、wholesale、price 这类平台买家的修饰词。

用之前一律回搜索引擎查量、看结果页。客户在平台上搜「厂家」，不等于页面可以这样写。

## 9. 社区与问答

工程师社区和问答里的提问，是最真实的措辞。

| 海外 | 看什么 | 怎么搜 |
|---|---|---|
| Reddit、Quora | 原话、推荐和吐槽 | 站内搜索；Google 加 `&udm=18` |
| Electronics Stack Exchange | 技术问题的标准问法、标签 | 按标签看高票问题标题 |
| EEVblog、原厂论坛 | 停产替代、料号、设计问题 | 站内搜索；`site:` 加品类词 |
| YouTube | 选型、拆解、接线视频的叫法 | 搜索框联想 |
| LinkedIn | 行业帖子、公司页的叫法 | 站内搜索帖子 |

| 国内 | 看什么 | 怎么搜 |
|---|---|---|
| 微信搜一搜 | 公众号文章标题、下拉词 | 搜索框下拉 |
| 知乎、CSDN、电子类论坛 | 工程师提问、高赞回答的叫法 | 站内搜索；`site:` 加品类词 |
| 抖音、小红书 | 站内搜索下拉、热门问题 | 搜索框下拉；付费工具可挖 |
| 百度爱采购 | 厂家、批发、现货类说法 | 站内搜索 |

一条论坛帖往往同时出现几种需求：停产替代 + 料号 + 怎么选。高频问题补进问题集和博客选题，料号和叫法补进关键词表。

为什么也要看社区：AI 回答常引用社区内容。Profound 统计 Perplexity、Google AI 概览引用最多的域名是 Reddit（约 6.6%、2.2%），ChatGPT 是 Wikipedia（约 7.8%）（2025-06-05，厂商数据，看方向）。

## 10. AI 扩词

缺灵感时用，排在最后，可信度最低。AI 不知道真实搜索量，给出的数字看着合理却是编的；它也可能编出没人用的说法。

五步：
1. 写提示词：按属性、意图细类分组，另列同义叫法；
2. AI 列说法：只要说法，不要数字；
3. 合表去重：和其他来源的词合到一张表；
4. 查量、看结果页：KE、规划师、后台；回搜索引擎看前排；
5. 标来源：来源写「AI」，只有 AI 一个来源的词不算需求证据。

提示词模板（把 [ ] 换成自己的）：

```
【任务】为「[品类]」列出 [目标市场] 的 [硬件工程师和采购] 可能使用的 [语言] 搜索说法。
【要求】分两层分组：按属性（参数规格、封装结构、应用行业）和按意图
（信息词：参数资料、选型方法、原理机制、技术对比；
 商业词：比较挑选、替代查询、找厂家、找供应渠道、询价），另列同义叫法；每组 10 个以内。
【约束】不要给搜索量或任何数字；不确定是否有人这样说的，标「待验证」。
【输出】表格：说法｜属性｜意图细类｜同义叫法组｜待验证（是 / 否）。
```

人工把关：
- 每个词去工具查量，看后台有没有展示；
- 回搜索引擎看结果页，意图对不上的剔除；
- 比较类按比较对象归类；
- AI 给的任何数字都不用；拿不准是否有人这样说的，标「待验证」，不进页面。

## 11. 来源怎么记

- 每个词的「数据来源」可多选：KE / GKP / GSC / 必应 / 百度 / 广告 / 竞品工具 / 平台 / 询盘 / FAE / 社区 / AI。
- 搜索量单独记工具、市场、取数日期：`140（KE 美国，2026-10-13）`。
- 来源个数就是打分时「需求证据」的依据：两个以上来源出现算有需求证据（经验做法）。
- 同一个词不同日期取数会不一样，所以每个数字都写日期。
