# 关键词研究与布局

目的不是找出越多的词越好，而是让每个页面只承接一个清楚的主题，让每个有价值的词都有且只有一个主承接页。

## 1. 分类：先按意图，再看属性

**第一层：意图**（主轴）

- **信息词**：想了解原理、参数、怎么选、怎么用。
- **商业词**：想买、想找货源。下分九类：
  1. 产品浏览
  2. 比较挑选
  3. 替代查询
  4. 找厂家
  5. 找供应渠道
  6. 询价
  7. 现货与下单
  8. 样品
  9. 定制
- **导航词**：搜品牌、搜站名。

注意区分两种「比较」：比技术、比规格的，是信息词里的技术对比；比品牌、比供应商、比可买的产品（best、top、review）的，才是商业词里的比较挑选。

**第二层：其他维度**（用来细分，不和意图并列）

- 属性：品类、型号、品牌、参数、应用场景
- 范围：核心词、长尾词
- 热度：常年稳定、阵发性

**不按人群给词分类。** 正确的顺序是从词出发：

> 词 → 可能是什么人在搜 → 他的痛点 → 我们的方案 → 承接页

先给词贴「工程师词」「采购词」的标签再找页面，容易张冠李戴。

## 2. 选主题词

1. **看量和意图**：搜索量要有，意图要和页面一致。大词的流量里，非目标人群可能占大头（例如找零售成品的个人买家）。要看搜索结果页和下拉词判断，不能只看搜索量。
2. **选贴近买家的叫法**：同一个东西有好几种叫法时，选搜索量大、买家常用的作主题词。其他叫法放在首段或问答里各提一次。
3. **同义词要验证**：
   - 两个词搜索结果的前 10 名重合多，说明搜索引擎当成同一主题：只建一页，量大的作主题词。
   - 重合少，就分成两页。
   - 真同义词的搜索量可以相加；同一个词的不同写法（空格、连字符、大小写）不能重复相加。
4. **修饰词先查量再用**：manufacturer、supplier、wholesale、厂家、供应商这类词，很多时候量接近 0。查了再决定，不要想当然。
5. **身份词按事实写**：标题里写「制造商」「代理」「供应商」，必须和口径登记一致（自己生产才能写制造商），并且有搜索量支撑。不同品类可以不同，规则要写进站点档案。

## 3. 「词 → 承接页」对照表（必做）

动笔写文案之前先做这张表，一个词一行：

| 词 | 意图 | 搜索量 / 证据 | 主承接页 | 本页怎么用 | 其他页怎么用 |
|---|---|---|---|---|---|
| | | | | Title / H1 / 正文 / 问答 | 只放链接，锚文字写这个词 |

规则：

- **一词一主页。** 两个页面争同一个词（抢词），排名会互相拖累。
- **首页只主打主题词，加 3–5 个辅助词**（通常是产品线名）。长尾词交给分类页、应用页、文章，首页只放链接过去。把几十个目标词全塞进首页，主题会被稀释，还会和自家分类页抢词。
- **上下级不抢**：上级页的品类通用词不塞进下级页；下级页写本系列的变种、型号、属性。
- **商业词进产品类页面，信息词进文章。** 两个例外：
  - 「型号 + 规格书」这类词，进型号页；
  - 设计和应用类的词，进应用领域页。
- 拿不准的长尾词，放进最相关的已有页面，不为它单独开新页。

## 4. 数据从哪来

- **关键词工具**：搜索量、出价、相关词、竞品排名词。查询要花额度，先列词表再批量查，记录花费。
- **搜索控制台**：自己已经有曝光的查询词。优先做「有曝光、排第 8–30 名」的词，见效最快。
- **搜索框下拉词、相关搜索**：中文市场的主要依据。多数关键词工具没有中国数据，下拉词能说明有人在搜、在怎么说，但不能当搜索量用。
- **竞品**：竞品排名的词、竞品型号（采购常直接搜竞品型号找替代）。
- **B2B 平台、电商平台、社区问答**：买家的真实说法。

每个词都标上数据来源和取数日期。

## 5. 汇报什么

汇报集中度，不汇报「覆盖了多少个词」：

- 核心词占比：主题词加辅助词，占页面上所有产品名词的比例。
- 主题词出现的位置：Title、H1、首段、H2。
- 是否有抢词：同一个词的主承接页是否唯一。

「50 个词覆盖了 50 个」听起来好，往往意味着主题被稀释了。

## 6. 和用户讨论时讲清的几件事

- **收录**和**排名**是两回事：词放杂了一般不影响收录，影响的是排名和匹配。
- 页面层面做到满分，也只能拿到和站点权重相称的词。真正带流量的往往是外链、分类页、型号或对照页，以及针对设计者的技术文章。
