# 数据来源与降级

原则：有什么数据用什么数据，缺的不硬凑。每个数字都写清楚三件事：来源、取数日期、口径。缺的数据列进报告的「数据说明」，对应评分项标「未验证」，并选定一种处理方法，全报告统一：

- **剔除**（推荐）：这一项不计分，把它的满分从总分里减掉，再折算回 100。
- **保守给分**：按已知最坏的合理情况给分，在扣分原因里注明「未验证」。

## 数据清单

| 数据 | 回答什么问题 | 没有时怎么降级 | 注意 |
|---|---|---|---|
| **直接请求线上页面**（必有） | 状态码、跳转链、head 标签、正文、结构化数据、robots.txt、站点地图、llms.txt | 无法降级，这是底线 | 用多个 UA 请求，见下文；记录请求时用的 UA |
| **渲染后的页面**（无头浏览器） | 脚本渲染出的内容、隐藏元素、布局、性能 | 只看源码，报告注明「未渲染」，正文口径可能偏差 | 收起的问答要算进正文；隐藏在 textarea、JSON 里的数据不算正文，但要算进 HTML 体积 |
| **搜索控制台**（谷歌 Search Console、百度资源平台、必应站长工具） | 收录量、查询词、曝光、点击、排名、抓取错误、人工处置 | 用 `site:` 查询估量级；用日志看抓取 | `site:` 只能估量级；必应的 `site:` 从本机查常不准，不计分 |
| **服务器访问日志** | 蜘蛛抓了多少、抓了哪类页、拿到什么状态码 | 无替代，报告注明 | 蜘蛛真假要反查：IP 反解出域名，再正解回同一 IP。要去掉自家代理、回源、监控的流量 |
| **关键词工具** | 搜索量、出价、相关词、域名排名词、外链 | 中文市场用搜索框下拉词、相关搜索、指数 | 多数工具没有中国数据。下拉词只能说明有人在搜、怎么说，不代表搜索量。查询要花额度：先列清单再批量查，记录花了多少 |
| **网站统计** | 着陆页流量、跳出、转化 | 用搜索控制台的点击代替 | 统计口径和搜索控制台不同，不要混着加 |
| **数据库只读查询** | 全量字段值、批量统计、后台存的值和页面渲染出的值是否一致 | 全站抓取后反推 | 只读事务；不打印连接密码；中文字段注意字符集 |
| **网页存档**（如 Wayback Machine） | 域名历史：以前是谁的、放过什么内容 | 搜旧网址、问域名卖家 | 新接手的域名、收录异常时必查 |
| **外链数据** | 外链数量、来源质量、垃圾外链占比、锚文本 | 搜索控制台的「链接」报告 | 小站在第三方库里覆盖不全，「查不到」只能说明「几乎没有」 |
| **搜索结果页** | 意图判断、同义词是否算同一主题、竞品格局 | 无 | 看前 10 个结果；国内搜索引擎查询注意防刷，频率放低 |
| **AI 回答抽查** | AI 搜索有没有提到本站、引用官网，引用的说法对不对 | 用站方公开的监测数据，注明「未独立复核」 | 选 5–10 个目标问题实际问一遍，记日期和原问法；这是抽样，不是统计 |
| **结构化数据校验** | JSON-LD 能否解析、能否进富媒体结果 | 脚本解析 JSON，并和可见文字比对 | 官方测试工具要人工打开，结果截图存证 |
| **性能** | LCP、CLS、INP、请求数、体积 | 本机无头 Chrome 按手机档模拟，跑 3 次取中位数 | 公共测速接口有每日额度；和线上对比时，两边都要开压缩；TTFB 波动大时扣掉 TTFB 再比 |

## 多 UA 请求

至少比较下面几种 UA。看状态码、跳转目标、标题、正文长度、robots 标签：

- 桌面浏览器
- 手机浏览器（真人）
- 谷歌爬虫（手机版、桌面版）
- 百度爬虫
- 必应爬虫
- AI 爬虫（GPTBot、ClaudeBot、PerplexityBot 等）

常见问题有这几种：

- 真人手机被跳到另一个应用（往往是 noindex 的单页应用），爬虫却拿到桌面页；
- CDN 按 UA 拦截或放行；
- 防火墙按频率把蜘蛛限流成 503。

`node scripts/seo_measure.mjs uacheck <网址>` 能一次比完。

## 抓取礼仪

- 并发低一点：海外站 4 个以内；有防刷 CDN 的国内站用 1 个，放慢速度。
- 监测请求的 UA 里带上可识别的标记，便于事后在日志里区分。注意：有的站内功能会把带 bot 字样的请求过滤掉，比如「热门搜索」「求购榜」。这时看到的数据和真人看到的可能不一样，要换成浏览器 UA 再看一次。
- 全程只读：不提交表单，不登录后台写数据。
