# 站点档案（模板）

每个站点建一份，命名为 `站点档案.md`，放在这个站的工作目录里。第一次用本技能时和站点负责人一起填；之后每踩一个坑，就补进第 7 节。

不知道的项写「未知」，不要猜。档案里写错的东西，会被后面每一次工作当成事实用。

**不要写进档案的东西**：密码、密钥、令牌。这些只写「存放位置 / 找谁要」。

## 7. 已知坑

每条写四项：现象、根因、规避、怎么查。下面是通用的几类，按本站实际情况改写或删掉。

| 现象 | 根因 | 规避 | 怎么查 |
|---|---|---|---|
| 部署成功，页面没变 | 文件在部署排除清单里，或被缓存层拦住 | 改之前确认文件在发布范围内；部署后查源站 | 打开线上源码，搜新加的标识 |
| 某个板块在另一个语言站或姊妹站静默消失 | 代码按标题或网址别名找数据，两站写法不同 | 按 ID 找数据 | 两站分别打开页面，数板块 |
| 上线后整类页面报错，检查却全过 | 模板调用了不存在的函数；语法检查不执行代码 | 用之前搜一下定义 | 部署后立刻请求该类页面 |
| 真人手机看到的和爬虫看到的不是一个页面 | 按 UA 跳转到另一个应用 | 规范页面要对所有 UA 一致 | 用多个 UA 请求，比较结果 |
| 标题前台显示和后台存的不一样 | 代码自动加后缀，或空值时用兜底 | 写之前先读出渲染规则 | 比较三样：后台原值、渲染规则、线上结果 |
| 小语种页面链接 404 | 新板块只在主语言建了目标页 | 按语言检查链接目标 | 每个语言版本跑一遍链接检查 |
