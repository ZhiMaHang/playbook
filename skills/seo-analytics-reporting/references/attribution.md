# 询盘归因

SEO 最终要回答「带来了几条询盘」。B2B 里这件事很难做准，所以原则只有一条：只报有证据的部分，先让每条询盘带上来源，再谈 SEO 带来了几条。

## 1 为什么难

示意路径（不是真实客户）：工程师搜规格书，从自然搜索进站 → 几周后同事直接输入网址再来 → 采购发邮件询价（没有来源标记）→ 销售跟进、样品、报价 → 几个月后下单（记在 ERP）。站内统计最多看到前两次访问，而且前提是访客点了同意。

| 难点 | 说明 |
|---|---|
| 周期长 | 选型、样品、验证、小批到量产，几周到几个月 |
| 多人参与 | 查资料的是工程师，发询价的是采购，人和设备都不同 |
| 渠道多 | 表单、电话、即时通讯、邮件；邮件和电话没有来源标记 |
| 统计看不全 | GA4 只记同意了的访问；跨设备、没登录的用户连不起来 |
| 回溯期有限 | GA4 关键事件的归因回溯期最长 90 天 |

## 2 各方法能回答什么

| 方法 | 能回答 | 回答不了 |
|---|---|---|
| GA4 报告归因（数据驱动 / 最后点击） | GA4 记录到的线上触点之间怎么分功劳 | 没同意的访问；邮件、电话、线下 |
| 表单记录来源（首次 / 末次） | 这条询盘提交时从哪进站 | 之前的多次访问；别人代填 |
| 问客户「从哪里知道我们」 | 补上邮件、电话询盘的来源 | 记忆偏差，常答「搜索」 |
| 离线转化回传 | 把 CRM 里的有效询盘、成交回传给广告平台或 GA4 | 只覆盖匹配得上的部分；有时间窗口 |

回传要点（官方）：GA4 Measurement Protocol 补充而不替代网页代码，要带 `client_id`；想归到某次会话，需在会话开始 24 小时内发送。Google Ads 用 GCLID 或「潜在客户增强型转化」（依据：Analytics 帮助 10597962；Measurement Protocol 文档 2026-06-08；Google Ads 帮助 2998031）。

「来自自然搜索」和「受自然搜索影响」分开报，不混算；报告里写清用的是哪种方法（业内说法，出处较弱，思路采用）。

AI 搜索让它更难：一部分比较、了解的过程挪到了点击之前，点击更少、意图更强（必应博客 2025-11-20）。

## 3 让询盘带来源

三件事一起做。

**表单隐藏字段**（业内通用做法，没有官方专页，推断）：访客第一次进站时，网站记下以下字段，提交表单时随隐藏字段写进 CRM：

| 字段 | 说明 |
|---|---|
| 首次着陆页 | 第一次进站落在哪页 |
| 首次来源地址（referrer） | 从哪个网站来 |
| UTM 参数 | source、medium、campaign（有就记） |
| 广告点击标识 | Google `gclid`、微软 `msclkid`、百度 `bd_vid`；网站跳转时不能弄丢 |
| GA 客户端编号 | 将来回传 GA4 用 |
| 末次来源与着陆页 | 提交前最后一次进站的来源 |
| 提交页 | 在哪页提交的 |

销售再标注有效性和阶段，需要时把结果回传给广告平台或 GA4。

**UTM 规范**：自己发出去的链接（社交帖子、邮件、目录站、展会资料）都加 UTM。

| 参数 | 必填 | 示例 |
|---|---|---|
| `utm_source` | 是 | linkedin |
| `utm_medium` | 是 | social、email、cpc |
| `utm_campaign` | 是 | 2026q4_ball_valves |

官方要求至少带来源、媒介、活动三个参数，缺了在报告里显示 (not set)（Analytics 帮助 10917952）。经验做法：统一小写；一张登记表管理所有链接，写清谁发的、发在哪、哪天发的。

**人工登记**：电话、邮件、即时通讯询盘，登记时问一句「从哪里知道我们」，写进来源字段。所有询盘都进 CRM 并标来源，不管从哪个渠道来。

登记表头见 [../assets/inquiry-source-log.csv](../assets/inquiry-source-log.csv)。

怎么判断做对了：每条询盘都有来源字段，「未知」的比例逐月下降。

## 4 判断一条询盘是否来自自然搜索：三级证据

| 级别 | 证据 | 例子 | 算不算「带来源的自然询盘」 |
|---|---|---|---|
| A 系统记录 | 隐藏字段记下来源是搜索引擎，且没有广告参数 | 来源 google / organic；着陆页是某分类页 | 算 |
| B 间接推断 | 询盘里的型号、着陆页和 GSC 的查询、网页对上 | 客户问型号 X；GSC 里「X datasheet」有点击 | 不算；单列「疑似」 |
| C 客户自述 | 客户说是搜索找到的 | 邮件里写「在 Google 上搜到的」 | 不算；单列 |

只有 A 级算进「带来源的自然询盘」。B、C 各几条分开写，不并进 A，不拿推断冒充事实。

## 5 报告里怎么写

| 情况 | 写法 |
|---|---|
| 来源字段还没上线 | 「带来源的自然询盘：未获取（表单不带来源）」；另写询盘总数和口径，标「来源未知」 |
| 部分询盘有来源 | A 级 X 条；B 级疑似 Y 条；C 级自述 Z 条；来源未知 W 条；总数 N 条（口径） |
| 有人要「估一个数」 | 不估。说明为什么：站内统计少计、询盘不带来源，任何乘法都没有依据；给出补来源的计划和日期 |
| 广告平台显示有转化 | 写明平台转化的定义（确认过没有），不等于询盘 |

不要做：用 GA4 自然搜索会话 × 询盘转化率推算；用 GSC 点击 × 某个比例推算；把总询盘按渠道流量占比分摊。

## 6 以后能做的（推断）

A 级数据够多以后（样本量至少几十条），按着陆页汇总询盘，和 GSC 网页点击放在一起，算「每 100 次点击带来几条询盘」，找出最值钱的页面；再拿这个结果反过来调整关键词表和页面优先级。样本少时只看方向。
