# GSC 效果报告：口径、限制与操作

GSC 是海外站最可信的一手数据，但它不是全量，也不是实时：它只给 Google 搜索结果里、能公开的、两三天前的那部分。本文件的功能和规则截至 2026-10（依据见各节），每季度按 Search Console 帮助复核一次。

目录：1 四个指标 · 2 按资源与按网页 · 3 平均排名 · 4 六个限制与报告前提 · 5 AI 功能的数据 · 6 筛选 · 7 正则 · 8 对比 · 9 品牌词筛选与查询分组 · 10 导出、存档、注释 · 11 巡检节奏

## 1 四个指标（官方定义转述）

| 指标 | 定义 | 别误读 |
|---|---|---|
| 点击 | 用户点了结果里指向你网站的链接，去的是 Google 搜索、探索、新闻以外的网页才算；返回后再点同一链接只算一次 | 点击由 Google 记，不受网站统计代码影响 |
| 展示 | 你的链接出现在用户看到或可能看到的结果里；轮播、折叠区一般要滚到或展开才算 | 展示不是搜索量：排不上的词，搜得再多也没有展示 |
| 点击率 | 点击 ÷ 展示 | 同样的排名点击率低，多半是标题和描述不吸引人（交 seo-tdk-page-elements） |
| 平均排名 | 每次展示取你网站链接的最高位置，再对所有展示求平均；只算 Google 搜索 | 官方说算法将来可能变 |

依据：Search Console 帮助 7042828、7576553（2026-10 访问）。

## 2 按资源汇总，还是按网页汇总

- 图表和「查询」等表格按资源汇总；「网页」表按网页汇总。
- 同一次搜索里出现你的两个网址：按资源算一次展示，按网页各算一次。所以网页表加起来常比总数多。
- 报告里：总数用图表上的数；网页之间比较用网页表；不把网页表加总当总数。
- 资源类型：网域资源含所有子域和协议（只能 DNS 验证）；网址前缀资源只含该前缀，可按路径另建（如 `/fr/`）。同一个站两种资源的数不一样，报告写清用哪一个，前后不换。

## 3 平均排名怎么读

平均排名按展示加权，新词、旧词一起算。演示（虚构值）：只有词 A 排第 3、100 次展示时平均 3.0；网站开始在排第 25 的新词 B 上也有 100 次展示，A 一点没变，平均排名变成 (3 × 100 + 25 × 100) ÷ 200 = 14.0。

- 网站在更多词上有了展示（哪怕排在后面），平均排名会「变差」；
- 一批排在后面的词消失（例如垃圾查询没了），平均排名会「变好」。

四条规矩：

1. 看具体词、具体页，不看全站平均。
2. 前后比较时，固定同一组词。
3. 展示很少时只看大概（几十次以内的词，名次波动很大）。
4. 排名类 KPI 用「目标词进前 10 的个数」。

## 4 六个数据限制与报告前提

| 限制 | 官方说法 | 会造成什么 | 怎么办 |
|---|---|---|---|
| 匿名查询 | 两三个月内搜索人数很少的查询不显示原文；计入图表总数，不进表格 | 按查询筛选后合计变小；小站可见查询可能只占少部分点击 | 报总数和可见部分；写可见查询覆盖率；匿名部分从网页维度看 |
| 行数上限 | 界面和导出最多 1,000 行；API 每站每天每种搜索类型 5 万行 | 查询、网页多的站导不全 | 用 API、Looker Studio 或 BigQuery（第 10 节） |
| 保留期 | 效果报告可看 16 个月 | 做不了更长的同比 | 每月导出存档；数据量大就开 BigQuery 批量导出（推断：越早越好） |
| 延迟 | 数据通常 2–3 天后可见 | 周一看不到上周末 | 写明「数据截至哪天」；周报区间截至 3 天前 |
| 切日 | 按美国太平洋时间切日；GA 按网站设的时区 | 和 GA4 的日数据对不上 | 跨工具比较用周或月 |
| 初步数据 | 24 小时视图的最新数据是初步的；日数据最近几天也会上修（实际观察，非官方说法） | 最近几天看起来像掉量 | 剔除最后 2–3 天，或标「初步」；算日均、达成率时另算一版去掉不完整日的 |

依据：Search Central 博客 2022-10-19；Search Console 帮助 96568、7576553；Google《Debugging drops in Google Search traffic》（2025-12-10）。

**报告开头先写五个前提**：资源（网址前缀还是网域）、搜索类型、国家筛选、日期区间和「数据截至哪天」、可见查询覆盖了多少点击。另写读数时间：GSC 页面上「上次更新」的时间并不固定，读数时记下来。

## 5 AI 功能的数据

| 场景 | 在 GSC 里怎么计 |
|---|---|
| AI 概览 | 整体只占一个位置，里面的链接都算这个位置；展示、点击按常规规则计；点里面的外部链接算一次点击 |
| AI Mode | 排名按普通结果页的规则算；追问算新的查询 |
| Search Labs 实验 | 不计入 |
| 搜索类型 | AI 功能的数据计入「网页」，也计入总流量，拆不出来（推断） |
| 生成式 AI 效果报告 | 2026-06-03 推出，08-31 起全球开放；只统计展示，可按网页（规范网址）、国家、设备、日期看；没有点击、点击率、排名和查询词；图表按资源、表格按网页汇总，合计可能对不上；展示太少或已退出时不显示 |
| 网页（多模态） | 2026-09-24 新增的搜索类型：来自 Lens、圈选即搜、上传图片的搜索 |

依据：Search Console 帮助 7042828；Google《AI features and your website》（2025-12-10）；Search Central 博客 2026-06-03、2026-09-24。

对报告的影响：

- 总展示涨了，不一定是普通结果的排名涨了。
- 生成式 AI 报告和效果报告的展示不相加、不相减。
- 有展示不等于正文被 AI 引用了（推断）。
- GA4 那边，从 AI 概览、AI Mode 点进来的访问算「自然搜索」，不算「AI 助手」渠道（Analytics 帮助 9756891）。

## 6 筛选

操作顺序：

1. 左上角确认资源。
2. 选搜索类型：默认「网页」；另有图片、视频、新闻、网页（多模态）。
3. 选日期：默认最近 3 个月，最长 16 个月。
4. 「添加过滤条件」：查询、网页、国家、设备、搜索结果呈现。
5. 切换下方标签看表；点表格里的一行，会自动按这一行筛选（最快的下钻办法）。

官方规则：查询、网页可选「包含」「不包含」「自定义（正则）」；可以同时按多个维度筛；搜索结果呈现一次只能筛一个；搜索类型和日期两个筛选一直在，删不掉（Search Console 帮助 17011165，2026-10-25 访问）。

常见错误：上次留下的筛选忘了删；按查询筛选后的合计当成总数；两份数据的资源、搜索类型、国家不一致却放在一起比。

## 7 正则（RE2）

GSC 的正则用 RE2 语法，三个默认：

- **部分匹配**：不加 `^` `$`，规律出现在查询任何位置都算命中，所以要用 `\b` 限定词边界；
- **不区分大小写**：要区分，在最前面加 `(?-i)`（官方帮助的说法；网上有文章说法相反，以官方为准）；
- **可反选**：选「不匹配正则表达式」，排除垃圾词、品牌词时用。

RE2 不支持向前看 `(?=…)` `(?!…)`、向后看和反向引用 `\1`，网上的 PCRE 写法要改写。

下面两张表里的 `\|` 是 Markdown 表格的转义，粘进 GSC 时写成 `|`。

| 写法 | 意思 | 例子 |
|---|---|---|
| `\|` | 或 | `datasheet\|pinout` |
| `^` `$` | 开头、结尾 | `^how` |
| `\b` | 词边界 | `\bbuy\b` 不命中 buyer |
| `( )` | 分组 | `^(what\|how\|why)\b` |
| `.` `?` | 任意一个字符、可有可无 | `push.?pull` |
| `*` `+` | 0 次以上、1 次以上 | `^abc.*datasheet` |
| `\d` `{n,m}` | 数字、出现次数 | `\b<料号前缀>\d{3,4}` |
| `(?-i)` | 改成区分大小写 | `(?-i)BRAND` |

**正则配方**（通用写法，按本站改；B2B 英文站适用）：

| 用途 | 栏 | 正则 | 说明 |
|---|---|---|---|
| 品牌 | 查询 | `<品牌名>\|<错拼>\|<域名主体>` | 本站定死写法，写进站点档案；会命中 `site:` 指令查询，要剔掉 |
| 找联系人类垃圾 | 查询 | `whatsapp\|sales manager\|trade agent` | 选「不匹配」；按本站实际补充（如城市名），补之前先看命中的是不是都是垃圾 |
| 站点指令 | 查询 | `^(site\|inurl\|intitle\|cache):` | 选「不匹配」 |
| 信息 · 问句 | 查询 | `^(what\|how\|why\|which\|when\|where\|who\|can\|does\|do\|is\|are\|should)\b` | 再按细类细分 |
| 信息 · 参数资料 | 查询 | `datasheet\|data sheet\|pinout\|footprint\|pdf\|spec` | |
| 商业 · 替代 | 查询 | `\b(equivalent\|alternatives?\|replacement\|replace\|cross reference\|substitute)\b` | |
| 商业 · 询价找厂 | 查询 | `\b(price\|buy\|cost\|quote\|stock\|suppliers?\|manufacturers?\|factory\|vendors?\|distributors?\|wholesale\|samples?\|oem\|custom)\b` | 一定先排除垃圾规则，否则「distributor + whatsapp」会被算成找供应商 |
| 长查询 | 查询 | `^(\S+\s+){5}\S+` | 6 个词以上；筛出来的多是垃圾和模板化 AI 长问句，要人工看 |
| 型号 | 查询 | `\b<料号前缀>\d{3,4}` | |
| 语言目录 | 网页 | `\.com/(fr\|de\|ja)/` | 按本站目录改 |
| 旧的日期网址 | 网页 | `/news/\d{4}-\d{2}-\d{2}-\d+/` | 改网址后新旧合并看 |
| 主力品类页 | 网页 | `/(<目录1>\|<目录2>\|<目录3>)/$` | 会连带命中小语种同名目录 |

写对了吗：先在短日期上试，看出来的词是不是都是你要的；再换成「不匹配」，看被排除的那部分有没有漏网的。

## 8 对比

操作：点日期或任意筛选 → 切到「对比」→ 选两段日期或同一维度的两个值 → 应用后表格多出「差异」列 → 按差异排序 → 点那一行，换网页或查询标签看原因。

| 对比 | 怎么设 | 回答什么 |
|---|---|---|
| 环比 | 最近 28 天对前 28 天；本周对上周 | 最近有没有变化 |
| 同比 | 今年某月对去年同月（16 个月内） | 排除季节 |
| 改动前后 | 改动前后各 28 天，避开更新期 | 改动有没有效果（见 effect-review.md） |
| 两个查询 | 品牌对非品牌；两个型号 | 哪一部分在变 |
| 设备 / 国家 | 桌面对手机；目标国家对全部 | 变化集中在哪 |

官方规则：同一时间只能有一组对比，新加的替换旧的；值太少的一组显示「~」；日期对比用按周或按月的粒度，避免星期几的影响（Search Console 帮助 17011165）。跨月比较用整月，写清天数，不折算日均。

## 9 品牌词筛选与查询分组

| 功能 | 推出 | 是什么 | 局限 | 怎么用 |
|---|---|---|---|---|
| 品牌词筛选 | 2025-11-20；2026-03-11 起向所有符合条件的网站开放 | Google 的 AI 判断查询是不是在搜你的品牌，含各语言品牌名、错拼、只指向你独有产品的查询 | 规则不公开；只适用顶层资源，要有足够查询量；可能误判；不影响排名 | 有就和自建正则对照着看 |
| 查询分组 | 2025-10-27 | Search Console Insights 里，AI 把同一问题的不同写法、错拼、不同语言合成一组，显示每组总点击 | 只给查询量大的资源；只看点击；分组会变 | 有就参考 |
| 自建正则和标签 | — | 自己定规则 | 要维护，会漏 | 报告和 KPI 用这一种：口径固定，能复现 |

品牌写法变了（改名、改显示名），先回来检查品牌正则，再出下一期报告。

## 10 导出、存档、注释

| 方式 | 行数上限 | 匿名查询 | 适合 |
|---|---|---|---|
| 界面导出 | 每张表 1,000 行 | 没有原文 | 日常查看；中小站按月存档 |
| Search Analytics API | 每站每天每种搜索类型 5 万行；单次 2.5 万行，要分页 | 没有原文 | 定时拉数、自建报表 |
| Looker Studio 连接器 | 同 API | 没有原文 | 做看板 |
| BigQuery 批量导出 | 不受每日行数上限 | 没有原文（以空值出现） | 查询很多的大站；长期存档 |

依据：Search Central 博客 2022-10-19、2023-02-21；Search Console 帮助 12918484。

存档（经验做法）：每月 1 日导出上月的查询、网页两张表，文件名写清站点、资源和区间；收录这类只显示当前状态的报告同一天读一次留档。

注释（2025-11 起）：效果报告图表上右键 → 添加注释，最多 120 个字符；每个资源最多 200 条，500 天后自动删除，暂不能编辑；能看这个资源的人都看得到，不写人名、电话；对比模式和 24 小时视图里不显示。标改版、上线、迁移、搜索引擎更新的日期（Search Console 帮助 16530728）。

## 11 巡检节奏（经验值）

效果报告之外的功能（网址检查、网页索引、站点地图、体验、增强功能、人工处置、安全问题、链接、设置）在这里只按节奏看状态、记异常；查到问题后的修复方案交给 seo-audit-remediation。

| 频率 | 看什么 | 合格标准 | 异常时 |
|---|---|---|---|
| 每周 | 消息和邮件：人工处置、安全问题、索引提醒 | 没有新告警 | 当天交 seo-audit-remediation |
| 每周 | 效果报告总量 | 没有异常波动 | 按 diagnosis.md 排查 |
| 每月 | 网页报告：重要页收录、新出现的未收录原因 | 重要页全部收录 | 记异常，交 seo-audit-remediation |
| 每月 | 站点地图：每个子地图的状态和发现数 | 全部成功，条数符合预期 | 同上；子地图条数掉了没有任何告警，所以要逐个看 |
| 每月 | 核心网页指标、HTTPS、增强功能 | 没有「差」的组、没有无效项 | 同上 |
| 每月 | 生成式 AI 报告 | 记下展示趋势 | 进 GEO 月报 |
| 每季 | 链接报告；用户和权限 | 没有陌生可疑大站；所有者至少两人，离职人员权限已清 | — |
| 改版、迁移前后 | 网页报告、网址检查抽查、站点地图 | 新网址收录、旧网址跳转 | 交 seo-audit-remediation |
| 更新推完一周后 | 更新前后各一周对比 | — | 填更新应对记录（diagnosis.md） |

每次巡检填一行结果，异常写处理人和日期，下月先看上次的异常处理完没有。频率按几千到几万个网址的站定，站小可放宽，改动频繁时加密。
